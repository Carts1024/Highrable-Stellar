# Decisions

This folder records durable repository decisions that future agents should not rediscover from scattered prose. An ADR should explain context, the decision, consequences, and evidence/source paths. It is not a substitute for current implementation notes.

## ADR index

- [[decisions/ADR-0001-Obsidian-Knowledge-Vault]] — establish the repository-native documentation/context layer.

## ADR format

- Status: proposed, accepted, superseded, or rejected.
- Date and scope.
- Context and constraints.
- Decision.
- Consequences/tradeoffs.
- Source/evidence.
- Follow-up or revisit trigger.
